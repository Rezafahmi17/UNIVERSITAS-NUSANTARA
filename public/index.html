Website ini dirancang khusus untuk praktikum Keamanan Sistem Informasi dengan 2 kerentanan yang sengaja diterapkan sesuai ketentuan tugas:

1. Percobaan Sandi Tanpa Pembatasan (No Rate Limiting / Brute Force) CWE-307

Endpoint: POST /api/login
Cacat Keamanan: Server tidak menerapkan mekanisme pembatasan frekuensi percobaan login (rate limiting), delay respon, CAPTCHA, maupun lockout akun setelah gagal berturut-turut. Penyerang dapat melakukan fuzzing/brute-force tanpa batas.

Perintah Scan Nuclei Template:
nuclei -u http://localhost:3000 -t nuclei-templates/no-rate-limit-login.yaml
2. Validasi Berkas Lemah (Unrestricted File Upload) CWE-434

Endpoint: POST /api/assignments/upload
Cacat Keamanan: Fitur pengumpulan tugas mahasiswa tidak memvalidasi ekstensi file yang diizinkan (whitelist) maupun inspeksi MIME type. File berbahaya seperti script atau webshell (.php, .html, .svg, dll.) dapat tersimpan dan langsung diakses melalui URL publik /uploads/<filename>.

Perintah Scan Nuclei Template:
nuclei -u http://localhost:3000 -t nuclei-templates/weak-file-upload.yaml
Perintah Menjalankan Seluruh Scan Nuclei:
nuclei -u http://localhost:3000 -t nuclei-templates/
